Окремий режим

Заявка зберігається і експортується для роботи майстра.

FAQ

Чи потрібно змінювати CRM?

Ні. BeautyBridge працює поверх існуючого процесу. Для доступного API використовується adapter; для private-систем — окремий private adapter; без CRM — manual mode.

А якщо майстер працює без CRM?

Є manual/home-master mode: заявки зберігаються в базі, надходять у Telegram і можуть бути вивантажені в CSV для Excel.

Що буде, якщо CRM тимчасово не працює?

Лід не пропаде: BeautyBridge створить ручну заявку і повідомить команду.
